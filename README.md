# 🚀 Employee Salary Prediction & EDA Dashboard

This project is an interactive data application built using **Streamlit**, **Pandas**, and **Scikit-Learn** in Google Colab. It demonstrates data cleaning, exploratory data analysis (EDA), visualizations, and a live Machine Learning prediction model.

---

## 📌 Project Features
1. **Dataset & Preprocessing:** Loads a simulated employee dataset and handles data cleaning.
2. **Exploratory Data Analysis (EDA):** Displays summary statistics and interactive charts.
3. **Machine Learning Model:** Trains a **Random Forest Regressor** to predict employee salaries based on experience, test scores, and weekly work hours.
4. **Live Prediction Interface:** Interactive sidebar controls to test custom inputs and view instant model predictions.

---

## 🛠️ Tech Stack & Libraries
- **Python 3.x**
- **Streamlit** (Interactive Web App)
- **Pandas & NumPy** (Data Manipulation)
- **Scikit-Learn** (Machine Learning Model)
